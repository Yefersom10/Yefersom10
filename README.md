## 🚀 Proyectos Destacados

### 🤖 Web Application con IA — *Full Stack* (🔒 En Desarrollo / Repositorio Privado)
Plataforma web moderna con servicios inteligentes integrados.
- **Backend:** Desarrollado con **NestJS** en TypeScript, aplicando arquitectura modular y consumiendo la **API de Anthropic (Claude)**.
- **Frontend:** Creado con **Next.js**, aprovechando Server-Side Rendering (SSR) y optimización de componentes.
- **Estado:** En fase de pruebas de integración, optimización de consumo de API y refactorización.

### 🚗 Picha Lavado — *Full Stack*
Sistema de gestión para un lavadero de autos.
- **Backend:** API REST en Spring Boot (Controller - Service - Repository) y MySQL.
- **Frontend:** Interfaz dinámica desarrollada en Angular.
- **Funciones:** CRUD de clientes/servicios, gestión de reservas y control de roles (Usuario/Admin).  
🔗 [Ver Repositorio](https://github.com/Yefersom10/Picha_lavado_grupo11.git)

### 📱 Clinic Manager — *Frontend Mobile*
Aplicación híbrida para la administración y gestión de roles en una clínica.
- Desarrollo frontend enfocado en UI/UX adaptables.
- Implementación de CRUD completo usando **Ionic + Angular**.  
🔗 [Ver Repositorio](https://github.com/Yefersom10/Clinic_Manager.git)

### 🎙️ SimpleSpeak Assistant — *Desktop App*
Asistente virtual de escritorio con interfaz gráfica interactiva.
- Desarrollado en **Python** utilizando **Tkinter** para la GUI y **Pyttsx3** para la síntesis de voz.  
🔗 [Ver Repositorio](https://github.com/Yefersom10/SimpleSpeak-Assistant.git)
